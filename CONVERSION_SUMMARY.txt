================================================================================
FEATURE CONVERSION METHODOLOGY
================================================================================

1. Direct Mapping (30-40% of features)
   - Features with identical semantic meaning
   - Example: UNSW "dur" = CICIDS "Flow Duration"
   - No transformation needed

2. Derived Features (20-30% of features)
   - Calculated from available features
   - Example: Fwd/Bwd splits from combined metrics
   - Mathematical relationships preserved

3. Approximated Features (10-20% of features)
   - Similar but not identical features
   - Example: IAT std ≈ IAT mean × 0.5
   - Close enough for pattern recognition

4. Filled Features (20-30% of features)
   - Features not available in source dataset
   - Filled with 0 (model learns unavailability)
   - Minimal impact on critical detection features
